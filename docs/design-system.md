## 一、现状分析

### 1.1 视觉风格

当前默认主题「纸墨」是一个**纸张与墨迹**的方向：

- 暖白纸底 `#f6f4ef`，纯白面板，发丝级边框 `rgba(30,30,28,.08)`，无阴影无模糊；
- 墨色侧栏 `#1e1e1c`，选中项只加深一档并带 2px 朱砂刻度；
- **朱砂 `#b3402f` 只出现在“轮到你说话”的位置**：发送按钮、当前会话、未读数、提到我的标签；
- 标题用宋体（Songti SC / Noto Serif SC），正文用系统无衬线；
- 五套主题：纸墨（默认）、经典（靛蓝）、暖调纸感（琥珀）、深色、新粗野。

方向本身是对的，和产品的性格（agent 在群里替你干活、人只做判断和拍板）能对上：纸面是工作记录，朱砂是红笔批注。

### 1.2 字体与排版

| 问题 | 事实 | 位置 |
|---|---|---|
| 字号阶梯失控 | 主样式表里**18 种字号**，同一类文字在不同页面用不同值：辅助文字 9/10/10.5/11/11.5/12/12.5/13/13.5/14 全部在用 | styles.css 全文件 |
| 正文偏小 | 消息气泡 14px，卡片正文 13px，元信息 11–12.5px；可读正文很少到 15–16px | styles.css:496 等 |
| 字重过密 | 600 用了 60 次、700 用 17 次、800 用 5 次；层级靠加粗而不是字号与颜色 | styles.css |
| 字体没有被 token 化 | `body` 硬编码字体栈（:96），纸墨主题的 `--font-ui` 几乎没有被使用；经典主题 `--font-display: inherit` | styles.css:86, :96；theme-paper.css:5 |
| 衬线只用了一半 | 宋体只用在品牌名、页面标题、文档标题；侧栏分组名、数字、空状态还是无衬线 | theme-paper.css:106–132 |

### 1.3 色彩体系

| 项 | 现状 | 问题 |
|---|---|---|
| 中性阶 | 纸墨一套 9 级墨阶（bg / card / inset / soft / soft-2 / soft-3 / line / line-strong / ink / ink-2 / muted / faint） | 名字是“用途”而不是“层级”，新增组件时需要猜用哪一级 |
| 强调色 | 纸墨：朱砂 `#b3402f`；另有 `--btn-brand` `--btn-ink` `--avatar-bg` `--err-ink-strong` 等组合色 | 已经是“派生色”思维，但只做了 4 个，其余（hover、active、选中底）还是临时拼的 |
| 语义色 | ok / err / warn 各有 ink、ink-strong、bg、line 四个值 | 命名不统一（`--err-1`、`--warn-2` 是历史遗留） |
| 对比度 | 5 套主题 × 15 组“底色 + 文字”组合实测**全部 ≥ 4.5**，最低 4.62 | 已达 WCAG AA，改造时须保持 |
| 透明色 | 深色主题大量 `rgba(255,255,255,.05~.16)` | 只能用于叠在固定底上的场景，换成另一种底就失效 |

### 1.4 布局与留白

| 问题 | 事实 | 位置 |
|---|---|---|
| 正文宽度三套 | 文档类页面 880px；管理台与输入区 1000px；聊天消息区无上限（只限制气泡宽度 660px） | styles.css:879, :541, :1733 |
| 页边距不规则 | 文档页 34 / 32 / 70（上下左右不一致，且不在 4px 网格上） | styles.css:879 |
| 间距不在网格 | 7px 16 次、9px 16 次、5px 16 次、11px 10 次、14px 19 次、18px 8 次 | 全文件 |
| 响应式断点零散 | 720 / 760 / 900 / 560（560 出现两次）；文档类页面只有 `.doc-inner` 一个断点，Friends / Agents / Account 的列表行没有断点 | styles.css |
| 侧栏 | 264px / 折叠 64px / 窄屏 210px | App.tsx:633, styles.css:199 |

### 1.5 组件设计

| 组件 | 现状 | 问题 |
|---|---|---|
| 按钮 | **15 种“看起来像按钮”的样式**：head-btn、mini、temp-btn、modal-actions、copy-btn、friend-add、login、send-btn、tool-btn、guide-tab、flow-tabbtn、side-tab、side-add、link、login-guide-btn、de-lang-btn | 圆角 6 档（6/8/9/10/12/999）、同为 13px 的按钮 padding 有 4 种、字重 400/500/600 三种 |
| 输入框 | 8 套样式 | 字号 13/14/16 三档、圆角 9/10/12/14、**全部没有显式高度**（靠 padding 撑）、focus 有三种写法 |
| 卡片 | resource-card / guide-step / flow-node / stat-card / friend-card / admin-panel / modal-card / resource-panel | padding 11–22 五档，阴影两档混用，resource-* 用了写死的颜色而不是 token |
| 弹窗 | `.modal-mask` + `.modal-card` | 没有 `role="dialog"` / `aria-modal`，Esc 只在 Chat / Flow / DraftEditor 里处理 |
| 图标 | ui.tsx 一套 21 个手绘线性图标，`strokeWidth: 2`、viewBox 24，基座统一 | 调用处尺寸 11/12/13/14/15/16/18 混用，没有尺寸尺度 |

### 1.6 微交互

- 23 处 `transition`，时长 0.12–0.2s，全部是“变颜色”；**没有 `@keyframes`、没有进入动画、没有位移反馈**；
- hover 有 43 处，主要靠 `filter: brightness(1.06)` 和背景变浅；
- 有两处 `translateY(-1px)` 的卡片悬停（guide-step、friend-card），其余卡片没有；
- 按钮没有按下反馈（按下与悬停同一种状态）；
- 焦点环是 `box-shadow: 0 0 0 3px var(--ring)`，只覆盖 `button / input / textarea`，**链接（a）和 select 不在内**。

### 1.7 是否存在 AI 模板化痕迹

| 痕迹 | 严重度 | 证据 |
|---|---|---|
| 紫色/靛蓝渐变 + 玻璃拟态 | 已消除 | 上一轮已把所有渐变、模糊、彩色光晕删掉，玻璃主题删除 |
| 每个头像一个随机渐变 | 已消除 | 改为单色墨阶 + 首字 |
| 标题下渐变装饰条 | 已消除 | `.doc-title::after` 已移除 |
| 三栏卡片网格 + e莫吉图标 | 不存在 | 界面本身是聊天/列表结构，没有卡片的“营销页”结构 |
| 统一大圆角 + 大阴影 | 部分残留 | 圆角 6 档并存、阴影 2 档没有使用规则 |
| 字号过小、字重过密 | **仍然存在** | 见 1.2 |
| 文案 | 基本是工具型中文，没有“赋能/无缝/一站式”类词；少量英文混排（Agent、agent）大小写不一致 | 见 2.6 |

**结论：** AI 模板感的主要来源已经从“装饰”转移到了**系统层面的不统一**——字号、圆角、按钮、表单、间距各写各的。下一步的价值在于收敛成一套能被组件直接使用的 token 和组件规范，而不是再加装饰。

## 二、Design System v1

> 这套系统只描述 Martin，不借用营销站的规则。原则：**安静的外壳，一个响亮的瞬间**——所有页面用同一套纸面、墨阶和朱砂，唯一的“响”是发送按钮、当前会话和未读数。

### 2.1 品牌与性格

| 项 | 定义 |
|---|---|
| 一句话 | 把 agent 拉进同一个房间，人只做判断和拍板 |
| 性格 | 克制、精确、有一点温度（红笔批注的温度） |
| 材质世界 | 纸、墨、朱砂、印章；代码用等宽字像打字机的字模 |
| 署名细节 | **朱砂刻度**：当前会话左侧 2px 竖线；**回车提示**：等宽字的小键帽（`⏎`、`⌘↵`） |
| 唯一高潮 | 发送按钮（实心朱砂）+ 未读数（朱砂数字） |

### 2.2 色彩

#### 中性阶（纸墨，默认）

| Token | 值 | 用途 |
|---|---|---|
| `--paper-0` | `#fbfaf7` | 最高层表面（弹窗、菜单） |
| `--paper-1` | `#f6f4ef` | 页面底 |
| `--paper-2` | `#f1eee7` | 输入框、嵌入区 |
| `--paper-3` | `#efece5` | 悬停底 |
| `--paper-4` | `#eae6de` | 按下底 |
| `--paper-5` | `#e3ded4` | 分隔块、禁用底 |
| `--rule-1` | `rgba(30,30,28,.08)` | 发丝分隔线 |
| `--rule-2` | `rgba(30,30,28,.16)` | 控件边框 |
| `--rule-3` | `rgba(30,30,28,.28)` | 强调边框、选中边框 |
| `--ink-1` | `#1e1e1c` | 标题、正文（对比度 ≥15:1） |
| `--ink-2` | `#46443f` | 次要正文（≥8:1） |
| `--ink-3` | `#7a766e` | 元信息、标签（≥4.6:1） |
| `--ink-4` | `#56595e` | 小号辅助文字（≥5.0:1，用于浅灰底） |
| 墨面（侧栏） | `#1e1e1c` 底 / `#ece8df` 字 / `#928d84` 次字 | 与纸面同一色相的明暗两侧 |

#### 强调色（朱砂）

| Token | 值 | 用途 | 对比度 |
|---|---|---|---|
| `--accent` | `#b3402f` | 发送、主按钮底、刻度、未读数字 | 与白字 5.49 |
| `--accent-ink` | `#9c3728` | 浅底上的强调文字、链接 | 与纸底 6.2 |
| `--accent-ink-strong` | `#7f2c1f` | 悬停态文字 | 8.3 |
| `--accent-wash` | `#fbefeb` | 提到我的标签底、浅选中底 | — |
| `--accent-line` | `rgba(179,64,47,.28)` | 强调边框 | — |
| `--btn-bg` / `--btn-ink` | `#b3402f` / `#fffaf6` | 实心按钮 | 5.49 |
| `--btn-bg-hover` | `#9c3728` | 悬停 | 6.8 |
| `--focus` | `rgba(179,64,47,.28)` | 焦点环 | — |

> 其他四套主题按同一结构给出派生值（经典靛蓝 `#5a5ddb`、暖调 `#a34a08`、深色 `#e7eaf3` 近白底深字、粗野 `#a34a08`），同名 token 逐一对应。

#### 语义色

| Token | 值 | 用途 |
|---|---|---|
| `--ok` / `--ok-bg` | `#4e8a5d` / `#eef3ee` | 在线、成功（不用亮绿） |
| `--err` / `--err-bg` | `#a0262e` / `#f8ebe8` | 错误、吊销、未读红点以外的红色 |
| `--warn` / `--warn-bg` | `#805a1c` / `#f8f1e2` | 紧急、过期 |
| 在线点 | `#4e8a5d`，带 3px `rgba(78,138,93,.16)` 静默光圈 | 唯一的“活着的”信号 |

规则：

1. 界面 95% 是中性色；朱砂在任一屏的表面积不超过 3%。
2. 实心朱砂**一屏只有一个**（发送），其余强调都用 `--accent-ink` 文字或刻度线。
3. 不新增色相；需要新色时先从语义色里取。

### 2.3 字体

| 角色 | 字体 | 用途 |
|---|---|---|
| 正文 / 界面 | `Inter` 400/500（中文落到 PingFang SC / 思源黑体） | 消息、表单、按钮、列表 |
| 标题 | `Songti SC` / `Noto Serif SC` 600 | 页面标题、房间名、弹窗标题、品牌名 |
| 代码 / 数字 | `JetBrains Mono` 400/500 | 代码、ID、序号、计数、键帽、时间 |

- 不超过两个字族 + 一族等宽。**不引入第三套字体**。
- 中文正文同样走 `--font-ui`；宋体只用于 16px 及以上的标题级文字。
- 数字统一 `font-variant-numeric: tabular-nums`。

### 2.4 字号体系（替换现有 18 档为 9 档）

| Token | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `--t-display` | 26 / 34 | 600 宋体 | 登录页品牌名、空状态大标题 |
| `--t-h1` | 20 / 28 | 600 宋体 | 页面标题（每个页面一个 h1） |
| `--t-h2` | 16 / 24 | 600 宋体 | 区块标题、弹窗标题 |
| `--t-h3` | 14 / 22 | 500 无衬线 | 卡片标题、表单分组名 |
| `--t-body` | 14 / 22 | 400 | 消息正文、列表正文、表单值 |
| `--t-body-lg` | 15 / 24 | 400 | 输入区、文档正文（阅读区域） |
| `--t-sm` | 13 / 20 | 400 | 辅助说明、卡片描述 |
| `--t-xs` | 12 / 16 | 500 | 标签、元信息、时间、序号 |
| `--t-mono` | 12 / 16 | 400 等宽 | 代码、ID、计数 |

- 不再使用 9 / 10 / 10.5 / 11 / 11.5 这些档位；任何 `<12px` 的文字都必须理由是“键帽或角标”。
- 字重只用 400 / 500 / 600。**取消 700 / 800**：层级靠字号和颜色。
- 层级公式：**同一屏内字号最多跨 2 档**（例如 h2 16 + body 14），靠颜色区分主次。

### 2.5 间距与布局

#### 间距（4px 网格，8 档）

| Token | 值 | 用途 |
|---|---|---|
| `--s-1` | 4 | 图标与文字、紧邻元素 |
| `--s-2` | 8 | 同一组内的元素 |
| `--s-3` | 12 | 列表行内边距、按钮组 |
| `--s-4` | 16 | 卡片内边距（紧凑）、区块内分隔 |
| `--s-5` | 24 | 卡片内边距、区块之间 |
| `--s-6` | 32 | 页面边距（窄屏）、大区块之间 |
| `--s-7` | 48 | 页面边距（宽屏）、标题与内容之间 |
| `--s-8` | 64 | 页面上下留白 |

- 删除 5/7/9/11/14/18/22/26/34 等非网格值；1–3px 只允许用于描边和刻度。
- 分组规则：同组内 ≤ 8，组间 ≥ 24。

#### 布局

| 项 | 规范 |
|---|---|
| 侧栏 | 264 / 折叠 64；分组标题 12px 500；行高 34；行间距 2 |
| 内容宽度 | **统一三档**：`--w-read: 880px`（文档、指南、流程图、表单）、`--w-app: 1000px`（聊天消息列、输入区、管理台表格）、聊天气泡 `min(660px, 78%)` |
| 页边距 | 宽屏 32/48，窄屏 16；所有页面用同一个 `.page` 容器 |
| 页面头部 | 每个页面一个 `.page-head`：h1（20 宋体）+ 一行说明（13 次要色），与内容左对齐 |
| 断点 | **两档**：`768px`（侧栏折叠为图标条、双栏变单栏）、`480px`（列表行加高、按钮全宽） |
| 圆角 | `--r-sm 6`（控件、标签）、`--r-md 10`（卡片、输入框）、`--r-lg 14`（弹窗、大面板）、`--r-pill`（只用于状态点/徽标） |
| 阴影 | 只有两档：`--shadow-1`（静止卡片的 1px 环境影）、`--shadow-2`（浮层）。纸墨主题下卡片**不用阴影**，只用发丝线 |
| 焦点 | 统一的 `:focus-visible`：`outline: 2px solid var(--accent); outline-offset: 2px`，覆盖 a / button / input / select / textarea / [tabindex] |

### 2.6 组件规范

#### 按钮（收敛为 4 种）

| 类型 | 高度 | 字号 | 圆角 | 用途 | 状态 |
|---|---|---|---|---|---|
| `.btn--primary` | 32 | 13 / 500 | `--r-sm` | 一屏一个主操作：发送、登录、加入、创建 | 悬停加深到 `--btn-bg-hover`；按下 `translateY(1px)` |
| `.btn--secondary` | 32 | 13 / 500 | `--r-sm` | 次要操作：取消、邀请、复制、修改密码 | 描边 `--rule-2`，悬停底 `--paper-3` |
| `.btn--quiet` | 28 | 12 / 500 | `--r-sm` | 图标按钮、工具条：模板、紧急、折叠、侧栏 + | 透明底，悬停 `--paper-3`，选中 `--accent-wash` + `--accent-ink` |
| `.btn--text` | 20 | 13 / 400 | 0 | 行内链接式按钮：注册、返回登录、退出 | 下划线画出（150ms），悬停变 `--accent-ink` |

- 删除其余 11 种按钮样式（head-btn、mini、temp-btn、login-guide-btn、de-lang-btn …）的独立尺寸，改用上面的 4 种。
- 按钮统一 `height` 而非 padding 撑高，保证行高一致。
- 禁用：底 `--paper-5`、字 `--ink-3`、无阴影。

#### 表单

| 项 | 规范 |
|---|---|
| 高度 | 输入框 36，文本域最小 96，下拉框与输入框同高 |
| 字号 | 14（值）/ 12（标签，`--ink-3`） |
| 圆角 | `--r-sm` 6（与 `--r-md` 容器嵌套时 = 10 − 4 = 6） |
| 边框 | `--rule-2`；焦点 `--accent` + 3px `--focus` 环（不改变高度） |
| 标签 | 始终显示在输入框上方，不用 placeholder 当标签；placeholder 只做示例 |
| 错误 | 输入框下方 12px 红色文字 + 边框 `--err`；表格行错误在行下方 |
| 分组 | 同组字段间距 12，组之间 24；标签与输入 4 |

#### 卡片 / 行

| 类型 | 规范 |
|---|---|
| 卡片 | padding 16 或 24；圆角 `--r-md`；边框 `--rule-1`；纸墨下无阴影；悬停（仅可点击）边框 `--rule-2` + 背景 `--paper-3`，**不上移** |
| 列表行 | 高 34（导航）/ 40（会话）/ 44（好友、Agent）；左 12 右 12；图标列固定 20px；间距 8 |
| 表格 | 表头 12 / 500 `--ink-3`，底 `--paper-2`；行高 44；分隔线 `--rule-1`；选中行 `--accent-wash` + 左 2px 刻度 |
| 弹窗 | 宽 420（表单）/ 560（详情）；圆角 `--r-lg`；遮罩 `rgba(24,23,21,.42)`；必须：`role="dialog"`、`aria-modal`、Esc 关闭、焦点陷阱、打开时聚焦第一个字段 |

#### 图标

- 尺寸只用 **14 / 16 / 18** 三档（对应 `--t-xs` 行、按钮、导航）；
- `stroke-width: 1.75`（视觉重量与 14px 正文匹配），`currentColor`；
- 图标列固定宽度，与文字间距 8。

### 2.7 文案

| 规则 | 现状 → 目标 |
|---|---|
| 页面标题 | 「指南与流程」→「接入指南」；每个页面一个 h1 |
| 按钮 = 动词 + 宾语 | 「发送」「加入群聊」「新建群聊」「生成配对码」「撤销」「续期」保持；「重置密码」→「重设密码」统一 |
| 术语统一 | `Agent` / `agent` / `Agent 协作` 统一为 **Agent**（首字母大写，作专有名词）；`human 成员` → `人类成员` |
| 元信息格式 | 时间统一 `HH:mm`（今天）/ `MM-DD HH:mm`（昨天以后），序号 `#12` 等宽字 |

## 三、改造计划（待确认后执行）

按「先收敛、再打磨」的顺序，每一步都能单独验收。

### 阶段 0：token 落地（不改任何视觉）

- 在 `styles.css` 新增 `--paper-* / --ink-* / --accent-* / --s-* / --r-* / --focus` 一整套 token，并把现有 token（`--bg`、`--card`、`--brand-1` …）**映射**到新 token 上；
- 五套主题各写一份新 token 值，旧名字保留为别名，保证旧样式不破。

**验收**：五套主题外观逐像素不变；对比度脚本仍全部 ≥4.5。

### 阶段 1：排版收敛（变化最明显）

1. 字号从 18 档压到 9 档：按上表逐条替换（`11px → 12px`、`12.5px → 13px`、`13.5px → 14px`、`15px → 14 或 16`）；
2. 字重压到 400/500/600，删除 700/800；
3. 所有页面统一 `.page-head`（h1 20 宋体 + 说明 13）；聊天的房间名除外（保持 16 宋体在对话头部）；
4. 数字统一 tabular-nums。

**验收**（行为级）：
- 五套主题下，任一页面中出现的字号集合 ⊆ 上表 9 档；
- 页面标题在所有页面都位于同一 x 位置、同一字号；
- 截图对比：欢迎/空状态、群聊、指南、管理台四页标题基线一致。

### 阶段 2：间距与布局收敛

1. 所有 padding / margin / gap 归到 8 档；删除非网格值；
2. 内容宽度三档落地（`.page--read` / `.page--app` / 气泡）；
3. 断点统一为 768 / 480，补齐 Friends / Agents / Account / Guide 的窄屏处理；
4. 侧栏行高 34、分组标题 12。

**验收**：
- 脚本扫描 CSS 中所有 `px` 间距值，非 4 的倍数（除 1–3px 描边、≤3px 偏移）为 0；
- 1440 / 1024 / 768 / 480 / 390 五个宽度下，所有页面无横向滚动、无内容重叠、侧栏在 768 以下折叠。

### 阶段 3：组件统一

1. 按钮收敛为 4 种，逐页替换（登录、聊天、好友、协作、设置、指南、流程图、管理台、访客页）；
2. 输入框统一高度 36 + 统一 focus 环；错误提示移到字段下方；
3. 弹窗补齐 `role="dialog"` / `aria-modal` / Esc / 焦点陷阱 / 初始焦点；
4. 图标尺寸归到 14/16/18，`stroke-width` 1.75。

**验收**：
- grep 统计：一条按钮规则覆盖所有按钮（无按钮使用自定义 height/padding）；
- 所有弹窗可用 Tab 循环、Esc 关闭、打开时焦点在第一个字段；
- 焦点环在 a / button / input / select / textarea 上一致显示。

### 阶段 4：微交互（克制版）

| 交互 | 规范 | 时长/曲线 |
|---|---|---|
| 按钮悬停 | 底色加深 14%，按下下沉 1px | 150ms 进 / 120ms 出 / 90ms 按下，`cubic-bezier(.2,.8,.2,1)` |
| 按钮按下 | `transform: translateY(1px)`（paper 下）| 90ms |
| 行内链接 | 下划线左→右画出 | 150ms |
| 列表行悬停 | 背景 `--paper-3`，当前行朱砂刻度不动 | 120ms |
| 弹窗出现 | 遮罩淡入 + 面板上浮 6px 并淡入 | 200ms / 120ms 关闭 |
| 侧栏折叠 | 宽度过渡 | 200ms |
| 页面进入 | **只做一次**：页面标题区淡入上移 4px（120ms），之后全部静止 | 全站一次 |
| 减少动态 | `prefers-reduced-motion` 下全部取消，仅保留颜色变化 | — |

- 不加滚动触发的逐个淡入、不加视差、不加气泡弹跳、不加无限循环动画。
- 唯一的“活性”是 Agent 在线点（静止的圆点 + 静默光圈，不做呼吸动画）。

**验收**：
- 截图对比：按钮悬停/按下、列表行悬停、弹窗打开三组状态各有一组前后截图；
- `prefers-reduced-motion: reduce` 下所有 transition 仅剩颜色属性；
- 全站无 `@keyframes`（除在线点的静默光圈）。

### 阶段 5：逐页走查与文案

1. 逐页截图：登录、群聊、私聊、好友、协作、设置、指南（5 个标签页）、流程图、管理台、访客页、草稿编辑器；
2. 每页检查：标题层级、空状态、错误态、加载态、长内容（超长群名、超长消息、20+ 成员）；
3. 文案按 2.7 逐条修订；
4. 响应式：390 / 480 / 768 / 1024 / 1440 各走一遍。

**验收**：
- 每个页面至少一张 1440 截图 + 一张 390 截图，人工过一遍；
- 20+ 成员的成员弹窗、超长群名侧栏、超长消息气泡均不溢出；
- 一轮完整对比度脚本运行仍全绿。
